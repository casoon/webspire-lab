# Beispiele

Dieser Ordner ist Referenzmaterial und wird nicht gebaut. Das Template selbst startet bewusst
ohne Kundenlauf und ohne aktives Briefing.

`nordwerk/` zeigt ein vollständiges Briefing und drei strukturell verschiedene Richtungen. Zum
Untersuchen oder Wiederherstellen in ein neues Lab-Projekt die beiden enthaltenen Ordner an die
jeweilige Projektwurzel kopieren:

```text
examples/nordwerk/design/briefs/nordwerk.md  → design/briefs/nordwerk.md
examples/nordwerk/lab/nordwerk/              → src/pages/lab/nordwerk/
```

Vor dem Kopieren die Endung `.astro.example` in `.astro` umbenennen. Die Endung hält Astro davon
ab, die Referenzdateien im Template mitzubauen.

Es ist eine Referenz für Dateistruktur, Token-Überschreibungen und den gemeinsamen Inhalt — nicht
eine vierte Phase oder ein zu übernehmendes Kundendesign.
